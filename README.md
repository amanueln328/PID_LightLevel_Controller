# Light Level PID Controller
## Overview
This project implements a real-time, closed-loop Proportional-Integral-Derivative (PID) control system using a Raspberry Pi Pico 2W. The user can set the setpoint light level using the potentiometer. Then that light level is maintained by adjusting the PWM output of an LED based on feedback from a photoresistor. Some black cardstock was used to surround LED and photoresistor to minimize effects of ambient lighting.
